# README #

Proporcionamos una implementación de un algoritmo de cancelación activa de ruido en tiempo real para gafas inteligentes (smart glass wearable) en MATLAB.
El algoritmo fue probado y adaptado para funcionar en un entorno real.

La implementación proporciona principalmente:

 * Implementación de algoritmos de filtrado adaptativo de vanguardia.
 * Extensión de los algoritmos de filtrado adaptativo para funcionar en un escenario de tiempo real.
 * Análisis de rendimiento de diversos algoritmos de filtrado adaptativo.
 * Implementación del marco completo de cancelación activa de ruido.
 * Datos de prueba y scripts.
